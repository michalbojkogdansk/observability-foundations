Architecture Deep Dive

Request Flow

1. Browser sends GET to regression-api.michal-bojko-gdansk.workers.dev
2. Cloudflare Worker checks Redis cache (Upstash) for a matching key
3. Cache hit → return cached JSON instantly from the edge
4. Cache miss → Worker forwards request to Render.com Python backend
5. Python/scipy reads data from Neon Postgres, runs regression
6. Result returned to Worker → stored in Redis (TTL 5min) → sent to browser

Cloudflare Worker (Abbreviated)

export default {
  async fetch(request, env) {
    const url = new URL(request.url);
    const cacheKey = url.pathname + url.search;

    // Check Redis cache first
    const cached = await env.REDIS.get(cacheKey);
    if (cached) return Response.json({
      ...JSON.parse(cached), _cache: 'hit'
    });

    // Forward to Render.com backend
    const resp = await fetch(env.BACKEND_URL + cacheKey);
    const data = await resp.json();

    // Cache for 5 minutes
    await env.REDIS.set(cacheKey, JSON.stringify(data),
      { ex: 300 });

    return Response.json({ ...data, _cache: 'miss' });
  }
}

Python Regression Engine (Abbreviated)

from scipy import stats
from scipy.optimize import curve_fit
import numpy as np

def linear_regression(x, y, slo_ms):
    slope, intercept, r, p, se = stats.linregress(x, y)
    breach_day = (slo_ms - intercept) / slope
    return { "slope": slope, "intercept": intercept,
             "r_squared": r**2, "p_value": p,
             "breach_day": breach_day }

def exponential_fit(x, y, threshold):
    def exp_func(t, a, b): return a * np.exp(b * t)
    popt, pcov = curve_fit(exp_func, x, y, p0=[y[0], 0.01])
    full_day = np.log(threshold / popt[0]) / popt[1]
    return { "a": popt[0], "b": popt[1],
             "doubling_time": np.log(2)/popt[1],
             "full_day": full_day }
